# Extracted ggml CPU arithmetic

`ggml_quants.c` owns the reference quantizers. `ggml_cpu_dots.c` builds twice, for AVX2 and AVX-512. `ggml_cpu_dispatch.cpp` selects the type traits for the detected CPU. The packed types and traits are declared in `include/basalt/ggml`.

The paired Q5_0 entry point shares packed-weight decoding between two Q8_0 activations. Each token retains the single-token FMA and reduction order. Keep the original dot for odd tails and preserve the per-ISA symbols generated by CMake. The row helpers read caller-owned weights and activations and write only the supplied output rows.
